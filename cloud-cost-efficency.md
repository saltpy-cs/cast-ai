# Cloud Cost Efficency
Cast.ai suite helps make sense of cost, attribute cost and optimise cost. It will provide reports and analysis around cost optimizations. It provides a single dashboard from which to disect cost and understand optimisations.

- Visualise current cost and optimisations
- Detailed and daily cost breakdowns
- Breakdown of costs by type eg network, compute etc

Requires install of read only agent which is free for any size and number of clusters.
